# Hệ thống quản lý Trung Tâm Ngoại Ngữ

## Chạy chương trình
1. Giải nén thư mục.
2. Mở `index.html` bằng trình duyệt, hoặc dùng VS Code + Live Server.
3. Chọn `Đăng nhập`.
4. Tài khoản demo:
   - Username: `admin`
   - Password: `123456`

## Chức năng
- Trang công khai: Trang chủ, Khóa học, Lớp đang mở, Giới thiệu.
- Trang quản trị: Dashboard và 9 trang quản lý.
- CRUD: thêm, sửa, xóa, tìm kiếm.
- Dữ liệu lưu bằng `localStorage`, nên không cần MySQL/PHP để chạy demo.
- Xuất dữ liệu từng trang ra CSV.
- Có dữ liệu mẫu để kiểm tra ngay.
- Responsive cho máy tính và màn hình nhỏ.

## Lưu ý
Đây là bản frontend chạy độc lập. Nếu cần triển khai thật nhiều người dùng, cần kết nối backend PHP/MySQL hoặc Node.js/API để dữ liệu dùng chung và đăng nhập có bảo mật.
